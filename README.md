## ✅ Resumo dos Requisitos (conforme PDF)
- Tipografia: fontes do Google Fonts, hierarquia clara e tamanhos legíveis.
- Cores: paleta harmoniosa (2–4 cores), contraste WCAG AA.
- Layout: uso de Flexbox e/ou Grid para estruturas de 2–3 colunas em desktop.
- Responsividade: breakpoints obrigatórios — mobile (≤767px), tablet (768–1023px), desktop (≥1024px).
- Componentes especiais: formulário de contato estilizado, tabela responsiva e galeria de imagens.
- Imagens: `max-width: 100%` e otimizadas (WebP/PNG/JPEG).

---

## 🛠️ Requisitos Técnicos e Boas Práticas
- Organização de arquivos com nomes sem espaços e em minúsculas.
- Uso de classes semânticas e seletores eficientes (evitar !important).
- CSS organizado por seções/componentes e bem comentado.
- Validação do CSS no W3C e testes em Chrome, Firefox e Edge.
- Framework opcional: `Bootstrap 5.x` ou `Tailwind CSS 3.x`.
